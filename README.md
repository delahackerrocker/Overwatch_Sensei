# Overwatch_Sensei
 A landscape mobile companion for Overwatch hero stats, matchups, and advice, built around swipe navigation.

Open the project with **Unity 6000.6.0f1**. The revival preserves the original navigation and updates DOTween to 1.3.030.

Hero content is still the legacy 32-hero dataset and awaits a separate refresh. Device builds are deferred.

See [revival status and editor checks](docs/REVIVAL_STATUS.md) and the [initial audit](docs/REVIVAL_AUDIT.md).
